## Found and fixed

- `herdr agent prompt` refuses `--until` without `--wait`.
  The Herdr reference used `--until working` alone, which would have failed every launch.
  Fixed in commit `fix(tstack): pass --wait with --until when prompting a Herdr agent` before the task ran.

## Gaps to watch

- The lead ran `how` and `why` itself instead of delegating the explainer subagent the `how` skill describes.
  The artifact held real runtime evidence, so the step was done, but not in the skill's dispatched form.
  For a one-file subsystem the skill's simple path is small, so this needs a larger task to judge.

  Same note as above.
