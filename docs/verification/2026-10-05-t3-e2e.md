## Found and fixed

- Main skipped `tstack-setup` once a global models file existed, so nothing excluded a new project's `.tstack/`.
  The router now has main run `tstack.mjs exclude` at intake, and this run shows it working.
- `tstack.mjs` exited 0 with no output when run through `~/.claude/skills/tstack`, because Node resolves the module to its real path and the entry check compared it with the symlink path.
  Main found this itself and logged it.
  Fixed in `fix(tstack): run the CLI when invoked through a symlink`, with a test that runs the CLI through a symlink.
