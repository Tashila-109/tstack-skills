# RESOURCES.md format

`RESOURCES.md` lists the sources lessons draw knowledge from and the communities that supply wisdom.

```md
# {Topic} resources

## Knowledge

- [Book: _The Rust Programming Language_](https://doc.rust-lang.org/book/)
  The official introduction. Use for: ownership, borrowing, traits, error handling.

## Wisdom

- [Rust users forum](https://users.rust-lang.org/)
  Moderated, answers from experienced users. Use for: code review, idiom questions.

## Gaps

- {An area the mission needs that no good source covers yet}
```

## Rules

- Keep only high-trust sources: primary sources, recognised experts, peer-reviewed work, and well-moderated communities.
  Leave out marketing dressed as teaching.
- Annotate every entry with one line: what it covers and when to reach for it.
- Group entries under Knowledge and Wisdom; an entry may sit in only one.
- List areas with no good source under Gaps, so later sessions know what to search for.
- Remove a source that proves wrong, shallow, or off-mission; five sharp sources beat thirty weak ones.
- If the human does not want to join communities, say so here.
